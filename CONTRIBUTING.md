# Contributing to Anmixiu

Anmixiu accepts only contributions that the contributor has the right to submit under the
project's MIT license. This policy is a provenance control; it is not a transfer of copyright or
a substitute for legal review.

## Source provenance

For every contribution:

- Write original implementation code from Anmixiu's requirements and tests.
- Do not paste, translate, mechanically rewrite, or closely adapt third-party source code unless
  its license has been reviewed and the required license text, copyright notice, attribution, and
  modification notice are included in the same change.
- Record any third-party source used in the pull-request description with its URL, exact revision,
  file path, and license. Documentation and examples copied from another project count as source.
- Do not submit employer-owned, client-owned, confidential, leaked, or otherwise restricted code.
- Treat AI-assisted output as unverified source: the contributor remains responsible for checking
  its provenance, license compatibility, and similarity to third-party code.

Reading a project to learn a problem class or public interface does not authorize copying its
implementation. When a clean-room implementation is appropriate, record the requirements supplied
to the implementer and keep the implementer away from the reference implementation.

## Developer Certificate of Origin

Every commit must include a `Signed-off-by` line created with `git commit -s`. By signing off, the
contributor certifies the [Developer Certificate of Origin 1.1](https://developercertificate.org/),
including that they created the contribution or otherwise have the right to submit it under the
project license.

Maintainers must not merge a contribution with missing provenance information, unresolved license
questions, or a missing sign-off.
